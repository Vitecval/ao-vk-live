# Global architecture material metadata

This table contains 2,631 named architecture texture assignments for the optional
**Global building materials** slider (`RVK_BuildingHD`). Windows, metal, painted
metal, concrete/stone, brick and timber receive different roughness/metallic
baselines and filtered world-space detail. Dark regions of window-tagged textures
receive smooth non-metal glass shading and a restrained glazing tint.

These are filename-inferred profiles, not 2,631 new paintings. The renderer also
uses a rough non-metal fallback on other opaque static/room geometry with normals.
Explicit ORM maps take priority. Characters identified by the equipment catalog,
UI, additive/transparent effects and terrain are excluded from this fallback.
Transparent game glass keeps its existing rendering. Global detail does not add
geometry or create room interiors; glazing tint and existing reflections provide
an approximation on the original window surfaces.

The C++ table is generated by `python tools/build-world-material-catalog.py`.
Optional local `--names` and `--index` inputs rebuild public identity/name metadata;
no original game pixels are read or shipped. Texture-quality copies alias their
full-quality IDs. The global pass needs no per-texture image allocations.
