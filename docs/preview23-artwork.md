# Preview 23 artwork coverage

The current library contains **14,317 unique replacement IDs** out of **14,753 indexed surface IDs** (97.04%), with **44,039 runtime texture maps**. Alternate styles and normal/material/emission maps do not count as extra original IDs.

Revision 32 added 197 individual artwork restorations and 714 terrain detail restorations using eight generated ground masters. The ground work preserves the native coarse painting, opacity and boundary pixels for smooth transitions. These are not 714 independent repaints.

**436 original-only IDs remain**, including 24 requests blocked by the image service. The rest include controls, masks, exact-layout graphics, unresolved visible art and uses that still require draw-role confirmation. Historical emission/mask categories are not all certified technical-only inputs. We do not claim a 100% repaint or 100% visible-world coverage.

See [the per-ID retention list](preview23-retained-originals.csv). Original alpha and functional effects retain their existing protection. The library contains no Living add-on payload.
