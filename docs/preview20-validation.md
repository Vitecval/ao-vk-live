# Preview 20 validation scope

The exact Preview 19 baseline is `build/preview19/source-final`, verified against
all 844 records in the preserved release SOURCE-FILES.json. Git HEAD alone does
not represent the release. Preview 19 archives and manifests remain unchanged.

The release imports frozen, stable worker handoff records and verified baked maps,
using the established incremental material catalogs. Source artwork remains in
worker and production libraries. Native terrain IDs, connected-family ownership,
original-art policies and unchanged equipment response tests constrain acceptance.

Only Building Weathering is merged from the isolated environment project. The
reviewed v2 classifier covers 92 original architectural IDs and preserves original
identity after HD attachment. Off has matched Preview 19 pixel parity in controlled
Vulkan comparisons. Other experimental environment features are excluded. Existing
production terrain, grass and foliage code remains intact.

Final counts, exact build/package hashes, completed test receipts, source inventory,
installation result and limitations are recorded in the release REPORT.md and
validation.json. Matched raw frames and diagnostic material draw evidence are
retained in build/preview20/weathering. These controlled renders are not a new live
gameplay capture; ICC, Tir/older settlement and industrial gameplay, moving models,
long sessions and final appearance require the user's evaluation. Database coverage
must not be presented as visible-world coverage.
