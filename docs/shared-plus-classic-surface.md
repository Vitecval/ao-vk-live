# Shared Terrain+ retains the 0.7.7 surface

The source snapshot in `build/horizon-0.7.7/engine-source/rvk/native_ground.cpp` always returns AO's submitted terrain from the Shared+ branch of `NativeGroundReplaces`. Only rocks, pebbles and material-residency bookkeeping run there. It does not replace the ground with Enhanced Ground patches.

The later Snow-only `SharedTerrainPatches` exception violated that separation. Shared+ now retains AO's submitted positions, indices, cutouts and LOD boundaries in every region, including Penumbra. Enhanced Ground remains an independent explicit mode. The decoration submission continues marking indirectly sampled material owners, including evicted maps, without submitting native terrain triangles.

AO's original lighting normals are restored in `ffp.vert`. The removed override rounded each vertex to the nearest height sample and replaced its lighting normal, also leaving the previously computed view-space normal inconsistent. Material projection now obtains a continuous direction in `terrain.glsl` by interpolating height-field gradients at the fragment's world position. This direction never changes positions or classic lighting. Shared+ colour blending no longer has the triangle's constant steepness forced into its weight. Steep geometric projection remains independently available for incoming HD soil/snow detail so the soft crest/toe join does not reintroduce top-down stretching. Flat geometry still excludes collapsed vertical projections.

Reviewed HD maps, native alpha, authored paving/ice protection, natural tile seam blending, snow powder/path masks, footprints and distant material filtering remain in place. No renderer build or GPU verification was run by this worker for this change.
