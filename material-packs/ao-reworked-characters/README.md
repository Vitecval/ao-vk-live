# 0.7.8 ao-reworked-characters

485 individually reviewed character and equipment surfaces: 422 equipment surfaces and 63 creature surfaces across 235 named families.

Enable Character & equipment materials, then select Artwork: Reworked. Standard Enhanced remains available; surfaces without a rework use the existing library. Enhanced textures must be enabled to show replacement colour. Existing saved preferences are preserved.

Artwork was individually reviewed against its source layout. Fit on every live game mesh has not been verified. This release includes the accepted surfaces; it does not claim complete armor, creature or world coverage. Held and pending drafts are excluded.

Source paintings and original game reference images are not bundled in player downloads. SOURCE-ART-INVENTORY.json records the accepted painting hashes. See CREDITS.txt and LICENSE-TEXTURES.md for provenance and distribution terms.
