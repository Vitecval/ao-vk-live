# Enhanced Original ICC — private test artwork

Three separate generated source images modernize the owner's verified original
floor `1010004:295610` and tiles `1010006:21` / `1010006:22`. Generation prompts
and source/runtime SHA256 values are preserved beside this file. Runtime map
baking uses `tools/bake-enhanced-original.py`.

Only playfield 655 uses this alternative. Personal overrides take precedence;
each diffuse/normal/ORM family must be complete or the existing family remains.
The existing AnarchyHD images are untouched. No wall materials are approved.

Private original reference pixels are outside the source worktree and must not
be packaged. Generated images used those references. That provenance alone does
not establish permission to redistribute derived artwork. Public redistribution
is **not approved** pending a documented rights review. These files are intended
for the owner's isolated local test candidate only. Actual in-game UV/visual fit
and user acceptance remain pending.
