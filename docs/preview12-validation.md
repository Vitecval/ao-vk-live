# Preview 12 implementation and validation

1. Root cause: AttachMaterialMaps revoked family visibility before consulting shared GPU objects. A cache hit returned without restoring it; polling after EndFrame prolonged fallback. Ready material sets now publish independently and are never hidden by aggregate family state.
2. Why 28 families were linked: shared texture ownership formed undirected edges, with transitive closure joining 2,617 resources. Ownership, model inventories, explicit providers and masks remain recorded. Their incidental connectivity no longer controls drawing.
3. Preserved dependencies: every declared D/N/ORM/E/height map within a material is required; one provider supplies the set. A missing/corrupt required map retains that resource's original or previously valid maps. Original alpha and GPU map reference counts remain supported.
4. GPU readiness: one queued publication validates images, views, bindless slots and mip uploads on the render thread. Failed creation cannot publish CPU wrappers. Upload barriers and deferred destruction remain unchanged. Threaded failure/warm-share regression passed.
5. ICC: IDs 297326 and 297327 retain the high-quality ICC provider and emission requirements. Material-only 295444 remains valid. A missing map on another ID cannot hide them.
6. Cold loading: worker look-ahead is bounded to four completed materials and a 12 MiB pre-decode threshold (plus one bounded material), under address-space checks. Completed uploads drain before BeginFrame, with the existing 12 MiB per-frame soft budget. No game reveal/loading hook or mandatory wait was added. Genuine cold first-visibility popping remains possible.
7. Shared Ground: the same embedded five masters, original palettes and masks. Verified terrain identities can receive world-space cliff projection even when rotated transition cells fail the square-tile fit; unrelated geometry is excluded.
8. Cliffs: reuse embedded Poly Haven Cliff Side albedo/normal/ORM through existing CliffTex/CliffRock projection. No new image generation, terrain AO, sun relighting, mesh deformation or global lighting changes.
9. Shared Ground+: reuse bounded nearby native pebble generation and existing sand ripple/parallax/normal functions. Optional height/type data capture is capped by playfield size and memory headroom. Native ground replacement stays off; no replacement patch mesh or sky-visibility calculation is built. Footprints and large scree are not added by this mode.
10. Material correction: ground 1010006:17 roughness 0.20 -> 0.40, metallic 0.85 retained, normal strength 0.65 -> 0.20. Only its normal and ORM file hashes changed. Ground RGB is still AO's; asphalt remains dielectric roughness about 0.32. Screenshot identity and remaining half-panel appearance require live picker confirmation; the image alone cannot prove the exact ID or eliminate every UV mismatch.
11. Ultra/manual: explicit Ultra selection sets TerraBlend=2; manual 1 selects ordinary Shared Ground and survives unrelated settings changes and restart through existing persistence. Existing fractional blend strengths remain compatible. GradeOn is off for new configs, saved values preserved. RenderBg inversely migrates old PauseBg preferences; new default off. WeatherMode remains Automatic by default.
12. Quick Controls: Graphics (preset/terrain/common quality), Performance (Render in Background and existing controls), Weather (named modes and intensity). They edit the same settings as advanced categories.
13. Packages: same DLLs for Full HD/Lite. Lite retains ground 17,20..26; embedded terrain masters and cliff images are in both DLLs. Full includes verified manifest-selected maps and generated atlases/provenance. Optional maps remain independent of core graphics. Installer switches editions transactionally, refusing modified owned files and preserving preferences/personal packs. Publishing helper targets Vitecval/ao-vk-live, verifies checksums and existing tags, and supports previews. It has not been run.
14. Artwork: the split record reader decoded texture 17824 (9,003 bytes, JPEG 256x256). Synthetic split headers/payloads, continuation files and truncation pass. 838 inactive sources are intact and image-valid: architecture 320, additional buildings 390, furniture 96, tech props 16, industrial props 16. No batch is newly complete. 16128/289525 are deliberate tiny original inputs. Detailed blockers are in material-packs/art-publication.json. No new image generation or blind activation.

Validation: x86 renderer/demo/harness build, atomic publication regression, six family pixel fixtures, 49 shared-ground fixtures, ICC missing-emission/provider overlap, missing/corrupt material isolation, warm aliases, terrain loader, Ultra/manual defaults and installer edition rollback are checked locally.
