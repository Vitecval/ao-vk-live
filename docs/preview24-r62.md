# Horizon 0.7.6 / Preview 24 r62

Vivid Tone's overall strength defaults to 0.5. The effect stays optional and off
by default. Existing saved strength values and the player's on/off choice are
preserved. The app and in-game setting descriptions use the name Vivid Tone;
the original attribution and MIT license remain in the bundled license notices.

This patch retains Horizon 0.7.5's named presets, update notices, Patch notes,
Suggestions and tray launch. Lite and Full ship the matching r62 renderer and
shader-preparation helper. Full reuses the existing 19 texture companions and
14,345 prepared material files. Lite downloads no texture archives.

The HD armor and creature rework is reserved for 0.7.7 and is not included here.
Standard Enhanced remains the default character artwork.
