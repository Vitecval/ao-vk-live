# Living Rubi-Ka asset provenance

These three models and four atlas textures were originally authored for this
experiment using tools/author-living-assets.py. No downloaded model, game asset,
AI concept image, production texture-worker art or Parallax Windows resource was used.
The authoring script is the editable design source; bind-pose OBJ exports accompany
the LRM2 runtime files. The service drone includes four independent rigid bones,
90 palette frames, scanner oscillation and two rotor animations. LODs omit small
hardware and then rotor blades; all use one shared material per asset.

Generated geometry and texture artwork: CC0-1.0 dedication, to the extent permitted
by law. This does not grant rights to Anarchy Online trademarks or original game art.
Source code retains the repository MIT license. Pillow/NumPy are authoring tools,
not runtime or ZIP dependencies. Fonts are rasterized from the local Windows
Consolas font and the font file is not redistributed.

V1 art status: evaluation assets, pending visual review. These three CC0 assets include no citizen, clothing,
walking/idle animation or wildlife asset is included. No claim of production
quality or AO-authored asset compatibility is made.

## V2 original AO asset reuse

The paragraphs above describe the three CC0 V1 evaluation models only. V2 adds
public resource-ID catalogs and independently implemented read-only preparation
tools under tools/living. Original AO mesh, texture and animation bytes, including
locally prepared LRM files and atlases, remain proprietary and are excluded from
Git and the public ZIP. The ignored private/v2 cache must not be redistributed.
Read-only reuse does not grant rights to the original assets or trademarks.

Existing local HD maps are used where present. Their material-worker source files
and installation files were not modified, and their pixels are not bundled into
the public package. Resource IDs, chosen original clip IDs, body/head attachments,
texture origins, cache hashes and metrics are recorded in original-catalog.json
and the owner-only asset preparation receipts. The independently authored code
uses repository-native format layout facts; it does not include another asset
library, unlicensed third-party parser code, proprietary DLLs or downloaded art.
The classic original geometry and mixed original/HD maps still need production
visual approval. They are not labelled newly finished modern artwork.

## V3 status

These three CC0 models are preserved historical V1 laboratory prototypes. They
are not the V3 people, wildlife, drone, aircraft or original fan. Current original
